# فروع نفحة بن

صفحة مواقع فروع عطارة نفحة بن، وهي اللي يفتحها الـ QR.

**الرابط الثابت:** https://ahmedalsoufi14-4r4s.github.io/nafhatbun/

## لا تغيّر هذي الأشياء (عشان الـ QR يظل شغال)
- اسم الحساب `ahmedalsoufi14-4r4s`
- اسم المستودع `nafhatbun`
- لا تحذف المستودع ولا تخليه Private

## إضافة فرع أو تعديل رابط
1. افتح ملف `branches.js` هنا في GitHub.
2. اضغط أيقونة القلم (Edit).
3. انسخ فرع كامل من `{` إلى `},` والصقه تحت آخر فرع، وغيّر بياناته.
4. اضغط **Commit changes**. الصفحة تتحدث خلال دقيقة أو دقيقتين، والـ QR نفسه ما يتغير.

مثال فرع:
```js
{
  name: "فرع جديد",
  area: "المدينة · الحي",
  map: "رابط قوقل ماب",
  phone: "+966500000000",
  hours: "يومياً من ٨ الصبح إلى ١٢ بالليل",
  soon: false
},
```

- لما يطلع فرع سوق سبعة على قوقل ماب: حط رابطه في `map` وغيّر `soon` إلى `false`.
- رابط قوقل ماب: افتح الفرع في التطبيق > مشاركة > نسخ الرابط.
